# **App Name**: INRTX Reserve DApp

## Core Features:

- Wallet Connection: Connect to MetaMask (EIP-1193) or WalletConnect to interact with the DApp.
- Token Purchase (USDT): Placeholder function to simulate buying INRTX-reserve tokens with USDT.
- Token Purchase (POL/MATIC): Placeholder function to simulate buying INRTX-reserve tokens with POL/MATIC, including live USD conversion.
- Purchase History: Store purchase records in Firestore after a successful simulated transaction.
- Sale Progress: Display total tokens sold vs. a configurable cap fetched from Firestore.
- Dashboard Metrics: Aggregate and display key performance indicators (KPIs) such as total buyers and collected currency amounts, fetched from Firestore.
- Price Updates: Use an external price feed API tool to display live POL/MATIC to USD prices.

## Style Guidelines:

- Primary color: Use a vibrant blue (#29ABE2) to represent trust and stability, reflecting the nature of a stablecoin reserve.
- Background color: Light gray (#F0F2F5), providing a clean and modern backdrop.
- Accent color: A bright teal (#008080) for interactive elements and CTAs, creating a strong visual contrast.
- Headline font: 'Space Grotesk' sans-serif font for headlines; body font: 'Inter' sans-serif for body; combine for a tech-forward feel.
- Use simple, outlined icons for a clean and modern look.
- Implement a mobile-first responsive design with clear, card-based layouts and subtle shadows.
- Use subtle animations, such as skeleton loaders and transition effects, to improve user experience.
