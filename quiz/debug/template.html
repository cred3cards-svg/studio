Debug Lab

Ten broken programs · prepared for Riyanssh Khanduja

Every program below is broken in exactly one place. They all come from the reaction-times scenario: ages 12 to 16, houses Saturn and Mars, reaction times in seconds.

Each level has two phases

  • Diagnose. Read the program and decide what kind of error it has, then tap the one line that is wrong. You are not told whether you were right — this part is marked silently.
  • Repair. Fix the code and run the hidden tests. You see which tests failed, the inputs they used and what your program printed, but never the expected answer. Work it out from the description.

Rules

  • Every repair is counted. Fewer attempts scores higher, so read the error before you change anything.
  • After 3 attempts you may skip a level, but a skipped level scores nothing for the repair.
  • Pasting into the editor is blocked. Type your fixes.
  • Change only what is broken. Rewriting the whole program is not a repair.
  • You are never shown your score. It goes in the report.
